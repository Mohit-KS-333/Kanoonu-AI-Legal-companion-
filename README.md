Kanoonu AI was initially developed using the Gemma 2 2B model.

During later development, the project was transitioned to Phi-3 Mini,
which was fine-tuned on Indian legal data and converted to
**GGUF (Q4_K_M)** format for efficient local inference.

**Initial Model:** Gemma 2 2B  
**Final Model:** Fine-tuned Phi-3 Mini – GGUF (Q4_K_M)

The final model is hosted on Hugging Face:
https://huggingface.co/tejasgowda05/Kanoonu-AI-Phi3-GGUF
